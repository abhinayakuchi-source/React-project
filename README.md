# React Hands-On 1–3

A beginner-friendly React project containing three hands-on exercises demonstrating Props, State, and Form Handling using React and Vite.

## 🚀 Live Demo

🔗 https://abhinayakuchi-source.github.io/React-project/

## 📌 Project Overview

This project was created as part of React hands-on practice.

It contains three hands-on exercises:

1. Hands-On 1 – Student Profile Using Props
2. Hands-On 2 – Student Marks Using Props + State
3. Hands-On 3 – Login Form Using State

Each hands-on is organized into its own component folder.

## 🎯 Hands-On 1 – Student Profile Using Props

### Objective

Create a reusable Student component and pass student details using props.

### Details Displayed

- Student Name
- Roll Number
- Course
- College

### Expected Output

Student Profile

Name: Rahul
Roll No: 101
Course: BCA
College: ABC College

### React Concept

Props are used to pass student information from the parent component to the Student component.

## 🎯 Hands-On 2 – Student Marks Using Props + State

### Objective

Combine props and state in a React component.

### Features

- Student name received through props
- Subject received through props
- Marks stored using React state
- Increase Marks button
- Decrease Marks button

### Expected Output

Student Marks

Student Name: Rahul
Subject: Java
Marks: 50

[ Increase Marks ] [ Decrease Marks ]

### React Concepts

- Props
- State
- useState
- Event handling

## 🎯 Hands-On 3 – Login Form Using State

### Objective

Create a login form using React state to store the values entered into the form fields.

### Features

- Username input
- Password input
- Login button
- Login validation

### Login Behavior

If both username and password are entered:

Login Successful

If either field is empty:

Please enter username and password

### React Concepts

- State
- useState
- Form handling
- Event handling
- Conditional logic

## ⚙️ How to Run Locally

1. Clone the repository:

   git clone https://github.com/abhinayakuchi-source/React-project.git

2. Open the project folder:

   cd React-project

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL displayed by Vite in your browser.
